# Issue tracker

Issues e pull requests ficam no GitHub, operados pela CLI `gh`.

- Ler: `gh issue view <número> --comments`
- Listar: `gh issue list --state open`
- Criar: `gh issue create --title "<título>" --body "<corpo>"`
- Comentar: `gh issue comment <número> --body "<texto>"`
- Fechar: `gh issue close <número>`
- PR: `gh pr view <número>`, `gh pr diff <número>`, `gh pr create`

Referencie issues nos commits com `#<número>`. Commit e PR sem menção a IA.

Se o projeto usar outro tracker, troque esta lista; as skills só leem este arquivo.
