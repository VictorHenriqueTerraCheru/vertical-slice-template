# Memória do projeto

`project-map.md` é o mapa curto do que existe: features, tabelas e rotas. Serve para a IA não varrer o repositório a cada sessão e para o conhecimento não depender da memória de uma máquina.

## Quando atualizar

- Ao criar, renomear ou remover feature, tabela ou rota.
- Ao terminar `ai/playbooks/iniciar-projeto.md` e `ai/playbooks/nova-feature.md`.
- Ao arquivar o molde `Todos`.

Atualize no mesmo commit da mudança. Regras não ficam aqui: ficam em `AGENTS.md`. O mapa só aponta e lista.
